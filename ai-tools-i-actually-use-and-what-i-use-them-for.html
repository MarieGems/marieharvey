AI Tools I Actually Use in My Business, and What For

← Back to Random Thoughts
Marie Harvey · September 20, 2026

This isn't a generic top-ten AI tools list. This is the exact stack actually running Marie Gems, Marie Glow Studio, and this site today, what each piece is for, and the one tool in the mix that's currently blocked and just not part of the real answer yet.

Claude Code writes and runs the actual pipelines

This isn't a chatbot I copy answers out of. It's the thing that reads and writes the real files behind every pipeline I run, drafts the posts, checks the batches, and keeps the whole system organized into one folder per brand. Everything else on this list is a tool it connects to, not a replacement for it, and it's the one constant across every business I run.

I picked up how to actually build agent systems like these inside a Skool community called Claude Code Club (affiliate link), which is genuinely where most of this stack started clicking for me.

Tailwind and Blotato get the actual pins and posts onto real platforms

Tailwind schedules Pinterest pins for Marie Gems and Your Kind Mind. Blotato handles Facebook, Instagram, Threads, and Twitter for Marie Gems' daily social batch, and, as of today, Marie Harvey's own Pinterest pins too, since this site never had a Tailwind account to begin with.

Where Shopify itself fits into all of this

Both of Marie Gems' pipelines pull real, live data straight from Shopify before drafting anything: which products are actually in stock, which ones sold well over the last thirty days, which blog posts are actually published versus just sitting in a draft folder. None of these pipelines are allowed to reference a product or a post from memory. Every fact gets checked against the live store first, every single run.

Flodesk, on purpose, without a send button

The Flodesk connection I use for list health checks has no campaign-send tool on it at all. That's not a limitation I work around, it's exactly why I trust it to run unattended: the worst it can ever do is write me a report or a draft email nobody's read yet.

A knowledge base I built instead of paying for one

Built September 16th: a local search tool over my own Shopify catalog and blog files, with no vector database and no ongoing subscription, tested against thirteen real indexed records before I trusted it. It answers questions like "has this story already been used" and "which posts already cover this topic" straight from files already sitting on disk, in seconds, for free.

A tool that just keeps my books honest

On the finance side, I run a simple import and reconciliation setup for bank and Shopify statement data that keeps every raw imported number in its own lane, completely separate from any category a person or an agent assigns to it afterward. It's not flashy, and it's not really "AI" in the way the rest of this list is, but it's one of the tools I'd genuinely miss most if it disappeared tomorrow.

The tools that actually build and deploy this site

Underneath the agents, this site itself runs on real animation libraries: a scroll-driven canvas effect for the homepage hero and smooth-scroll animation throughout, the same kind of effect that used to take a lot of hand-coded hours to get right on its own. Once a change is ready, it gets pushed to a standalone repository that a Git-based deploy tool on my hosting account pulls from automatically, so a real update reaches the live site without needing a developer on call for it.

What about AI image or video generation?

Honestly, it's not part of my real toolkit right now. My Higgsfield image-generation account is blocked at every model tried until I upgrade the plan, so it isn't something I'm actually using today, no matter how often it comes up elsewhere. Every photo and video on this site and in these posts is a real one of me or my actual work, never generated, which is exactly how I want it anyway.

Where a human tool still finishes the job

Every short video gets its final sound and touches added in CapCut, by me, before it's ever scheduled. AI gets the footage assembled and paced. I'm still the one who finishes it.
