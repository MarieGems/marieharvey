How I'm Actually Using AI Agents Across My Businesses

← Back to Random Thoughts
Marie Harvey · September 17, 2026

I run four real content pipelines across my businesses right now, one shared Pinterest pipeline covering three brands, two separate blog pipelines, and one daily social pipeline, plus a couple of smaller agents that only watch and report. None of them is one big "AI runs my marketing" black box. They're built out of small, named agents that each do one job, hand their work to the next agent in line, and stop dead at the one point where a mistake would actually cost me something.

What "AI agents" actually means in my businesses

An agent, the way I use the word, is a written job description with a narrow scope: read these specific files, do this one task, write the result somewhere specific, and never touch anything outside that lane. I've got agents that only draft Pinterest pins, agents that only check a finished batch for mistakes, and agents that only push an approved batch live. Splitting the work up this way, instead of asking one AI to "handle marketing," is the whole reason any of this is trustworthy enough to leave running unattended.

The Pinterest pipeline runs the same four stages on three different brands

Marie Gems, Your Kind Mind, and now this site all run the same shape of pipeline: one agent researches keywords and drafts the pin copy, a second resolves a real image, a third renders the actual pin graphic, and a fourth checks the whole batch for duplicates, broken compliance lines, and cut-off text before anything reaches a scheduler. Marie Gems and Your Kind Mind post through Tailwind. This site's pins started going out through Blotato for the first time today, since marieharvey.com never had a Pinterest pipeline before.

Two separate pipelines write my actual blog posts

Marie Gems' Purple Print blog gets seven posts a week, one per day, each following a different format: a how-to on Tuesday, a comparison table on Wednesday, a real story from my own life on Thursday. This site has its own separate pipeline for Random Thoughts, and the post you're reading right now came out of it. Neither pipeline can publish anything itself. Both stop at a finished, reviewable draft and wait for me.

A daily social pipeline replaced one that didn't sound like me

I used to run social posting through a cloud routine that posted real, true content but buried it in emoji and a voice that wasn't mine. I replaced it with a pipeline that drafts five real posts a day, pulled from actual products, actual published blog posts, or a real story from my own life, written the way I actually type, then checked by a second agent for anything off-voice before it schedules anywhere.

Two agents whose whole job is to watch, not act

Not every agent drafts content. One checks the "Unengaged" segment on my Flodesk list before every big send and tells me whether it's grown, whether a win-back email is overdue, and whether I'm safe to send to the whole list. It has no send tool on that connector at all, so the most it can ever do is write me a report or a draft I paste in myself. On the finance side, when bank and Shopify data gets imported, the raw numbers stay completely separate from any category I or an agent assigns to them, specifically so a wrong category can never quietly corrupt what actually happened in the account.

What ties every one of these pipelines together

Every one of them separates "draft" from "go live" into two different agents that can't skip past each other. That split is deliberate, not decorative. It exists because a pipeline that let one agent draft, check, and publish in a single pass has already gone wrong here once, on a different Pinterest batch, when broken pins went out live before anyone caught it. Rebuilding around separate stages with a hard checkpoint between them is what makes it safe to let the routine ones run on their own now.

Do any of these post or publish without me seeing them first?

The routine, proven ones do, now, though they didn't all earn that the same way. Marie Gems' Pinterest pipeline and its daily social pipeline both run fully on their own only after I watched weeks of clean batches come out right first, Pinterest since September 9th and social since September 15th. Your Kind Mind's Pinterest pipeline joined that same standing autopilot on September 17th, once its own run of batches held up. This site's brand-new Pinterest pipeline got there faster, on purpose: I put it on full autopilot after exactly one batch, the same day it launched, a deliberate call, not proof every pipeline earns that trust that quickly. Every batch, proven or brand new, still runs through a quality-check agent whose only job is finding a problem before it reaches anything live, and nothing outside an actually-proven daily lane goes anywhere without me saying so first for that specific batch.

If you want the longer version of why I ended up building this instead of hiring it out, the gap my web design degree never covered is a big part of the answer, and it's the same instinct behind the three skills I keep coming back to.
