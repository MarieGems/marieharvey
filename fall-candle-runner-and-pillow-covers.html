Is it too late in the season to add fall decor?

Not for pieces built to carry past Halloween. A cheesecloth table runner, a pumpkin-spice candle, and a set of plaid pillow covers all read as "cozy season" rather than "pumpkin patch," so they work through Thanksgiving and into the early weeks of decorating for Christmas, the same way my Metallic Gold Fall Table Runner already works right through Thanksgiving in a different post.

What is a cheesecloth table runner actually for?

A textured, loose-weave table runner for a table that already has a full spread on it. The Terracotta cheesecloth table runner, 120 inches is on my Amazon list, with no written note from me, so it is named here as a real item, not a reviewed one. A 120 inch length is built for a long table, so measure yours before you order, since a runner that is too long just pools on the floor at both ends.

What does the Yankee Candle Spiced Pumpkin actually add to a room?

Scent, not decor. The Yankee Candle Spiced Pumpkin, 22 oz jar is a well-known candle brand's take on the scent, and it is on my list with no personal note from me. A 22 oz jar is a large candle, meant to scent a whole room over a long burn time, not a small accent candle for a shelf.

The candle is the easiest one to give.
